## Optional Python SDK dependencies

`sdk/python/pyproject.toml` pins `cryptography==50.0.2` and `PyJWT==2.15.1`; its build backend requires `setuptools>=68`. These Python packages, their wheels, and their transitive/native dependencies are not bundled by the native application archive. They must be installed separately for the optional SDK. Their exact local package license files were not available during this notice review, so this document does not assert an exhaustive license inventory for those packages. Retain and review the licenses shipped with the actual installed distributions before redistributing an SDK environment, especially native cryptographic libraries.
