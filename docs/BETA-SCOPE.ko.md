# Reverse Artex 0.1.0-beta.1

[English](BETA-SCOPE.md) · 한국어

Reverse Artex는 직접 소유하거나 방어 권한을 받은 애플리케이션의 HTTP 활동을 관측하고 조사하는 데 쓰입니다. 첫 공개 베타는 로컬 평가 및 단일 호스트 연동용입니다. 로컬 콘솔을 관측 모드로 시작한 뒤 권한을 받은 센서를 연결하거나 함께 제공되는 JSONL 샘플을 분석하세요.

| 제공 기능 | 베타 범위 |
| --- | --- |
| 로컬 콘솔과 수집기 | 루프백 콘솔, 인증된 센서 수집, 파일 및 샘플 분석, 증거 검토, 수집기 중지 상태에서의 백업과 복원이 포함됩니다. |
| 서명을 검증하는 보호된 읽기 | 선택 사항인 정책 에지와 애플리케이션 SDK 연동입니다. 앱의 세션 및 권한 검사와 평가할 경로를 설정하세요. |
| V2 보존 원장 | Linux의 선택 기능입니다. 상태 디렉터리마다 쓰기 프로세스를 하나만 실행하고 중지 상태에서 만든 백업을 검증한 뒤 복원하세요. |
| AI 검토 지원 | 선택 사항인 로컬 모델 분석은 별도 설정이 필요합니다. Decisions는 기본적으로 꺼져 있습니다. 자동 차단, 정책 전달, 호스트 격리도 각각 명시적으로 설정해야 합니다. |

[빠른 시작](QUICKSTART.ko.md)에 따라 압축본을 검증하고 풀어서 시작하세요. 콘솔 접속 링크와 센서 토큰을 비공개로 보관하세요. 수집기를 정지한 상태에서 `config.json`과 `data/` 전체를 함께 백업하세요. 저장소 오류는 [운영 안내](OPERATIONS.md), 선택 사항인 V2 상태는 [보존 원장 안내](V2-RETAINED-JOURNAL.md)를 참고하세요.

최근 Linux 검증에서는 네이티브 에지와 패키지에 포함된 SDK를 연동한 애플리케이션을 통해 통제된 HTTPS 읽기 요청을 처리했습니다. 최대 부하 구간에서 180.2초 동안 요청 18,000건을 처리했고 읽기 지연시간은 p99 223.9ms였습니다. 단일 호스트에서 진행 중인 작업을 마친 뒤 쓰기 프로세스를 재시작해 첫 읽기가 성공하기까지 8.34초가 걸렸습니다. 전체 실행의 응답 18,757건은 모두 감사 기록과 일치했습니다. 수치는 해당 부하, 애플리케이션, 저장소 설정을 적용한 결과입니다. [ARTEX 검증 근거(영문)](VALIDATION.md#november-18-beta-runtime-and-load)

릴리스 인계 문서에는 플랫폼별 압축본 검사와 실행 검증 범위를 기록합니다. Linux는 단일 호스트 연동용 배포 대상이며 V2 보존 원장과 오프라인 검증기를 지원합니다. Windows amd64 ZIP은 로컬 콘솔 평가용이고 Windows의 지속 부하 검증은 진행 중입니다. [지원 환경(영문)](COMPATIBILITY.md)

실운영 승인에는 실제 배포한 ARTEX의 전체 브라우저 및 로깅 경로, 24시간 부하와 실제 7일 보존 용량, 독립 호스트 두 대 사이의 장애 전환 검증이 남아 있습니다. 보안 문제가 의심된다면 [보안 정책](../SECURITY.ko.md)의 절차를 따르고 공개 보고서에는 비공개 캡처나 자격 증명을 포함하지 마세요.
