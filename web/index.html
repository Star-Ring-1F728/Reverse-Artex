공개 베타 안내

첫 5분: 분석을 체험하고 내 센서를 연결하세요.

기본 · 관측 모드

샘플 분석부터 시작할 수 있습니다. 실제 수집과 사건 검토는 아래 순서로 연결하세요.

  1. 01 · 약 1분

    샘플로 분석 체험

    준비된 HTTP 이벤트 12건을 별도 메모리에서 분석합니다. 실제 수집 원장·사건·정책에는 반영되지 않습니다.

  2. 02 · 센서 준비

    내 서비스에서 이벤트 연결

    연결 설정에서 수집 주소와 센서 인증 토큰을 확인해 SDK 또는 수집 에이전트를 연결하세요. 이벤트 화면에서 실제 수신을 확인합니다.

  3. 03 · 경보 수신 후

    경보를 사건으로 검토

    실제 경보가 생기면 사건 기억의 ‘수집 증거 동기화’를 누르세요. 저장된 사건을 열어 근거를 검토하고, 선택적으로 Ollama의 도구 지원 로컬 모델에 조사를 맡깁니다.

기본 설정은 관측·탐지입니다. 경보는 공격 확정 판정이 아니며, 샘플 결과는 내 서비스의 탐지 성능이나 보호 범위를 증명하지 않습니다. 정책 전달·임시 대응은 별도 설정과 권한이 필요합니다.

HTTP 경보

활성 파일의 최근 200건

실제 수집한 HTTP 이벤트에서 탐지한 경보입니다. 사건 기억에서 수집 증거를 동기화한 뒤 근거와 판정을 보존하세요. 파일·샘플 분석 결과는 여기에 포함되지 않습니다.

HTTP 이벤트

시간이벤트테넌트경로상태

활성 JSONL 파일의 최근 200개 완료 레코드를 표시합니다. 이전 봉인 구간은 data 폴더에 보존됩니다.

학습·관측·검토 흐름

사건 검토

사건을 검토하고 학습 후보를 선택하세요.

사건 기억

동기화한 경보를 원본 증거 해시와 함께 보존합니다. 경보만으로 공격 확정 라벨을 부여하지 않습니다.

권한·행위 맥락 v2 관측

설정 확인 전

실행 중 수집기의 기록이 완료된 사건을 고정 후보로 관측합니다. 관측 불가 사건도 함께 기록하며, 같은 증거의 반복 확인은 새 표본으로 세지 않습니다.

연결 확인 중
선택 기능입니다. Ollama를 별도로 실행하고 도구 호출을 지원하는 로컬 모델을 준비하세요. 먼저 사건 기억에서 실제 경보를 동기화하고 저장된 사건을 선택하면 모델이 근거를 조회하고 조사 기록을 남깁니다. 샘플 분석 결과는 조사 사건으로 저장되지 않습니다.
분석은 정책을 변경하지 않습니다. 임시 대응은 별도 설정에서 허용한 경우에만 사용할 수 있습니다.

이벤트 파일 분석
정규화된 HTTP 이벤트 JSONL을 실제 탐지 엔진으로 분석합니다. 분석은 실시간 수집 원장과 별도의 메모리에서 실행합니다. 샘플과 업로드 파일은 수집 원장·사건 기억·정책 실행에 반영되지 않습니다.
분석 결과
별도 분석
내 센서 없이 먼저 체험할 수 있습니다.왼쪽의 ‘샘플 12건으로 기능 확인’을 누르거나 정규화한 JSONL 파일을 선택하세요. 결과는 이 화면에만 표시됩니다.


센서 연결
센서 연결 정보
수집 서버가 실행 중이어도 센서가 자동 연결되지는 않습니다. 아래 주소·테넌트·센서 ID에 맞춰 SDK 또는 수집 에이전트를 설정하고, 센서 인증 토큰을 Bearer 헤더로 전달하세요.
콘솔 접속 키와 센서 인증 토큰은 서로 다릅니다. 센서 토큰은 등록한 수집 에이전트에만 전달하세요.
